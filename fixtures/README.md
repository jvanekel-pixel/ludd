# Fixtures

Real design files for the golden tests in `engine/tests/test_golden.py`.

These are personal and often purchased designs, so everything here except this
README is git-ignored. CI runs without them (the golden tests skip); run them
locally with `cd engine && uv run pytest`.

Embrilliance `.be` working files are kept for reference but can't be read
(proprietary format); export them to PES from Embrilliance to test them.
